# ボス専用BGM

このフォルダは、ボスごとの専用戦闘BGMを置く場所です。フォルダ名は boss_id（`RBMVisualAssets.APPEARANCES` の値。戦闘背景の `assets_bossmaker/battle/backgrounds/` と同じ名前）です。

| フォルダ | ボス | 曲 | 曲の大きさ → 曲ごとの調整（＋全体の調整 -3dB） | ループの戻り先 |
|---|---|---|---|---|
| `musha/` | 朽ちた機械武者 | `musha_normal.ogg`（覚醒前） | -34.3 LUFS → +10.3dB（実際は +7.3dB） | 12.4688 秒（9小節目の頭） |
| | | `musha_awakened.ogg`（覚醒後） | -37.9 LUFS → +13.9dB（実際は +10.9dB） | 12.46965 秒（9小節目の頭） |

ほかのボスの boss_id: `slime`（スライム）・`wolf`（狼）・`knight`（騎士）・`dragon`（竜）・`ghost`（幽霊）・`golem`（ゴーレム）・`astronaut`（宇宙飛行士）・`gentleman`（異形紳士）。

## ファイルの決まり

| 置く場所 | 使う時 |
|---|---|
| `<boss_id>/<boss_id>_normal.ogg` | 戦闘の始まりから（覚醒の無いボスは、この1曲だけ） |
| `<boss_id>/<boss_id>_awakened.ogg` | 覚醒した後、戦闘の終わりまで |

- 形式は Ogg Vorbis（`.ogg`）。曲の長さ・サンプリング周波数は自由（44.1kHz・48kHz のどちらでもよい）。
- 曲のファイルは編集しない。音量とループの戻り先は、鳴らす側の設定で決める（下の手順）。
- 覚醒後の曲が無いボスは、覚醒した後も覚醒前の曲（その音量）を続けます。どちらも無いボスは BGM なし（今までどおり）で、エラーにはなりません。

## 追加の手順（例: 竜の覚醒前・覚醒後）

1. `dragon/` フォルダを作り、`dragon_normal.ogg`・`dragon_awakened.ogg` を置きます。
2. Godot で取り込みます（エディタを一度開く、または `Godot --headless --path . --editor --import --quit`）。`.ogg.import` ができます。
3. **ループ:** 2つの `.ogg.import` の `[params]` の `loop=false` を `loop=true` にします（エディタなら「インポート」タブで「ループ」）。
4. **ループの戻り先**（`loop_offset`、秒）を決めます。決め方（2026-10-17、ユーザーの基準「違和感がなく、曲をできるだけ削らず、途中で切れたように聞こえない」）:
   - 曲の終わり → 頭のつながりを聞く。終わりが盛り上がったまま静かな前奏へ戻るなど、途中で切れたように聞こえるなら、曲の終わりの小節と同じ形の「つなぎ」が曲の中にある所（例: 前奏の最後の盛り上げ → 本編の頭）を探し、その次の小節の頭へ戻す。前奏は戦闘の最初の1回だけになる。
   - 戻り先は、小節の頭のすぐ後（数ミリ秒以内）の、曲の終わりの値とつながる段差の小さい点にする（小節の線ちょうどは波の途中のことがあり、プチッと鳴る）。
   - 頭へ戻っても自然な曲は `loop_offset=0` のまま（曲を削らない）。
5. もう一度取り込みます。
6. **音量:** 曲の大きさ（LUFS）を測り、`src/bossmaker/rbm_boss_bgm.gd` の `BOSS_BGM` に `"normal_db"`・`"awakened_db"` を書きます（値 = `REFERENCE_LUFS`（-24）− その曲の LUFS）。測り方: `ffmpeg -i dragon_normal.ogg -af ebur128 -f null -` の最後の「I:」。
   ```gdscript
   const BOSS_BGM := {
   	"musha": {"normal_db": 10.3, "awakened_db": 13.9},
   	"dragon": {"normal_db": 8.0, "awakened_db": 7.5},
   }
   ```
7. 確かめる: `tests/bossmaker/test_rbm_boss_bgm.gd`（命名規則・`loop=true`・戻り先が曲の中）→ `tools/verify_boss_bgm_gpu.gd --boss=dragon`（本物の戦闘、音入りの動画）→ 3周以上続けて鳴らして継ぎ目を聞く。

戦闘のコードは触りません。TEST BATTLE・クリアチェック・挑戦のすべてで、そのボスの戦闘に自動で使われます。

## 鳴り方（`src/bossmaker/rbm_battle_bgm.gd`）

- 戦闘が始まったら覚醒前の曲を頭から流し、ループします。登場演出があるボスは、登場が終わってから流します。
- 覚醒の演出が始まったら曲を消し（0.6秒）、演出が終わって覚醒が表示されたら覚醒後の曲を頭から流します。
- とどめ・全滅の命中で曲を消します（1.2秒）。勝利・敗北の演出と結果の間は鳴らしません。
- やり直しは頭から流し直します。REWIND は、戻った先の状態（覚醒前／覚醒後）の曲にします。
- 戦闘の画面を出たら（画面が隠れたら）すぐ止めます。ホーム画面のモニター（戦闘の音を消したプレビュー）では鳴らしません。
- 曲は `Music` バス（Master へ送る）で鳴らします。音量の設定を作る時は、このバスの音量を変えます。
- 再生器は1つだけなので、2曲が同時に鳴ることはありません。

## 音量の考え方

- 曲ごとの大きさを `REFERENCE_LUFS`（-24 LUFS）にそろえて鳴らします（曲ごとの仕上がりの差をなくす）。
- 全部のボスの BGM をまとめて上げ下げしたい時は、`RBMBossBgm.ALL_DB`（dB）を変えます。今は **-3dB**（2026-10-17、攻撃の効果音と合わせるため、ほんの少し下げた）。実際に鳴る大きさは -27 LUFS 相当です。
- 効果音は今の大きさのままです。BGM を上げすぎると攻撃の効果音が埋もれ、音割れ（マスターが 0dB を超える）の危険も増えるので、変えたら戦闘の動画で聞いて、マスターの最大を測ります（`docs/quality/AUDIO.md` §6・§8）。

## 特別なパスを使いたいとき（任意）

ファイル名を変えたい、別のフォルダの曲を使いたい場合だけ、`BOSS_BGM` に `"normal"`・`"awakened"` でパスを書きます（`ROOT` からの相対パスか `res://` から始まるパス）。書いたものが命名規則より優先されます。
