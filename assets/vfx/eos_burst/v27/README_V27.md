# ソティリス Eos Burst V27

最新の実機動画を基準に、カットインを完全削除し、振り下ろしをソティリスの体の前側へ修正した版です。

## V26からの変更

- カットイン画像、preload、ノード引数、タイマー、再生関数、シグナルをV27の実行経路から削除
- 振りかぶりは1ポーズだけ後方へ取り、その直後に剣を頭上から右前方へ通す構成へ変更
- 実際の振り下ろしとなるフレーム8〜10では、剣先を必ず柄より右側へ配置

- 剣オーラの追従座標を新しい前方軌道へ更新
