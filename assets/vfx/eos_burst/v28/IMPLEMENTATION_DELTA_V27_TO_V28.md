# V27からV28への実装差分

V27の画像やタイミングを作り直す必要はありません。修正対象はキャラクター表示の所有権だけです。

1. Eos用に専用Sprite2Dを2つ用意する
2. 通常表示中のソティリスをoriginal_sotirisへ渡す
3. 専用Sprite2Dをmotion_aとmotion_bへ渡す
4. 3ノードが同一参照にならないようにする
5. 専用Sprite2Dを通常Spriteより前面へ固定する
6. キャラクターループ内でframeとvisibleを毎フレーム再設定する
7. 通常Spriteはループ内で毎フレーム非表示へ戻す
8. スキル終了時に通常Spriteの状態を復元する

motion_aまたはmotion_bへ、待機AnimationPlayerが操作しているSprite2Dを流用してはいけません。待機アニメーションがframeを0へ戻し、同じ不具合が再発します。

カットインを復活させず、SWORD_SEGMENTS、CHARACTER_FRAME_TIMES、RELEASE_FRAME_INDEX、斬撃後の素材は変更しません。
