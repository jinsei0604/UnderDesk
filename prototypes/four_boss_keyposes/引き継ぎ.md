# メイチャレ　新ボス4体のキーポーズ

各ボス21枚、合計84枚。すべて背景透過の全身PNG。足元基準をそろえた状態で、1枚ずつ独立して使える。

## 最初に見る画像

- `boards/lion.png`、`flower.png`、`lava.png`、`clock.png` は各ボスの全21ポーズ。上から覚醒前単体、覚醒前全体、覚醒、覚醒後単体、覚醒後全体。足元の小さな目盛りが共通原点。
- `boards/density.png` は覚醒後の既存ボス、今回の採用立ち絵、描き起こした攻撃ポーズを戦闘表示倍率で比較したもの。
- `boards/battle.png` は20場面の戦闘位置比較。`battle/<ボス名>/` には元の1280×720サイズの確認画像がある。採用済みの戦闘キャプチャーへ合成した静止画。

## ファイルの使い方

`sprites/<ボス名>/<技の種類>/` に連番順のPNGを収録。例は `sprites/lion/pre_single/lion_pre_single_03_attack.png`。4体とも原寸320×180px。左上を (0, 0) とした共通の足元原点は **(176, 155)**。1280×720の戦闘確認画像では最近傍2倍で、その点を画面の (780, 474) に置いている。

同じ原点で画像を切り替えると、踏み込みや反動の位置が引き継がれる。獅子の覚醒前単体3枚目には浮きが入っている。自動トリミングを使う場合は `poses.json` の `bbox` 左上を描画オフセットとして保持する。座標は原寸px、右端と下端は範囲に含まない。

| 技の種類 | ポーズの順番 |
|---|---|
| pre_single / post_single | 構え → 予備動作 → 一撃 → 振り抜き |
| pre_all / post_all | 構え → 溜め → 発動 → 余韻 |
| awaken | 採用済み覚醒前 → 異変 → 変質① → 変質② → 採用済み覚醒後 |

## 原画と仕上げ

正式採用済みの原寸立ち絵を参照し、技ごとに全身を描き起こした原画シートを `source_sheets` に収録。覚醒の両端は採用立ち絵そのものを共通キャンバスに配置し、中の3枚を専用ポーズにした。覚醒後は獅皇・カラー女王・給仕長がB案、巨神がA案。

原画から各ポーズを切り出し、体の面積と姿勢を基準に縦横比を保って原寸へ縮小した。ディザを使わず、各形態の正式な立ち絵から抽出した色へ合わせ、変質中は両形態の色を使用。輪郭のアルファは透明・不透明の2値。素材は静止画で、再生尺やホールド時間は設定していない。
