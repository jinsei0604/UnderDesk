## 登場（2026-11-14 ユーザーの案）
- `encounter/intro/rbm_intro_lava.gd`（つなぎ）＋ `rbm_lava_fx_intro.gd`（中身）。画面の右上から溶岩の塊が降ってきて地響きとともに小山になる → だんだん激しく震える → 白熱してふくらみ一気に爆発（ヒットストップ）→ 爆発の中から両腕を広げた巨人（覚醒前全体の3枚目）→ 構え・題字。爆炎は少し育った所から出す（出始めの小さな形が尖った星に見えた）。カメラは寄らない（揺れだけ）。
- 演出は画面が黒から出た所（`LEAD` 0.36秒）から始め、音（`intro.wav`）も同じ時刻から鳴らす。

## 撃破（2026-11-14〜16）
- `rbm_lava_defeat.gd`（つなぎ）＋ `rbm_lava_fx_fall.gd`（覚醒前）・`rbm_lava_fx_fall_awakened.gd`（覚醒後）。全ボス共通のとどめのスローの後に続く（胸の光の円と火花は出さない）。
- 覚醒前: うずくまる姿（覚醒の2枚目）→ 炉の火が消えて灰色に冷える（湯気・震え）→ ひびが入ってかけら → 上から四角い粒でほどけ、岩が転げ落ちて冷えた岩の山が残る。
- 覚醒後（覚醒前より派手に）: 熱が暴れ出す（足元に火口・割れ目から溶岩・オーラが燃え上がる）→ 最後の大噴火（天への炎の柱・溶岩の大爆発・衝撃の輪）→ 柱の中で巨神がほどける → 柱が地面から離れて上へ抜ける → 冷えていく火口の上に岩の山。
- 2026-11-15 ユーザー「覚醒後の撃破の炎の柱が変に見切れている」: 伸び始めの柱が平らな箱に見えた → 出始めから画面の上まで届く高さで頭は丸く（`eruption.gdshader` の `round_top`）、根元が真横の一直線で切れた → 火口の内側に収めて下端を火口の縁の楕円に沿わせ網点でほどく（`soft_base`・`flare`）、衝撃の輪の奥側が柱を横切った → 輪を柱の後ろへ、熱のゆがみの輪はやめた、最後に柱が四角い影のように残った → 下端から地面を離れて上へ抜ける（`lift`）。これらの値の既定は承認済みの技と同じ見た目のまま。
- 岩の山は結果の画面まで残る。本体の色（冷えて灰色になる・照り）は共通の撃破の描き方の掛け算の色へ近づけて移す。
