# Art Direction（Makers & Challengers の見た目の方向性）

[PRO_QUALITY_BIBLE.md](PRO_QUALITY_BIBLE.md) の判断基準が優先する。
目的は「プロっぽく」という曖昧な指示を減らし、このゲームらしい見た目を具体的に伝えること。

**このファイルに書いていない方向性を、AI（Claude Code / Codex）が新しく決めない。** 必要になったら下の記号で「未決定」と書き、ユーザーに判断を求める。

| 記号 | 意味 |
|---|---|
| 【固定】 | ユーザーが決めた・動画で承認したこと。変えるにはユーザーの判断が要る |
| 【現状】 | ゲームを調べて分かった今の作り。方針として決まったわけではないが、勝手に変えない。新規制作はこれに合わせるのが基本 |
| 【未決定 / USER DECISION REQUIRED】 | まだ決まっていない。AIが決めない |
| 【判断の問い】 | 見た目を作る・評価する時に確かめる問い（外部資料の原則と既存の規約から）。新しいデザインの決定ではない |

---

## 1. 全体
- 【固定】戦闘・キャラ・タイトルの部屋はドット絵（UI_UX §11）。
- 【固定】スチームパンク系（歯車・真鍮・機械都市）のUIは採用しない。
- 【固定】技の演出はキャラ・ボスごとに固有。属性が同じでも見た目・時間割を共有しない。共通にするのは基礎部品（揺れ・Hit Stop・残像・衝撃波・破片・移動・SE・Flash・後始末）だけ。新しいキャラ・ボスが「どんな演出か」を楽しみにしてもらうため。
- 【固定】タイトル画面とボスの部屋はCodexの担当。部屋は承認済みのものだけを登録する（UI_UX §7）。
- 【未決定 / USER DECISION REQUIRED】ロゴを絵として作るか、今の文字のロゴのままか（QUALITY_AUDIT QA-32）。今の文字のロゴ（Oxanium）は承認済みのものとして使われている。

## 2. Pixel Art の基本方向
- 【現状】キャラ（味方・ボス）: 高解像度の原画を表示の高さへ縮小し、1280×720上で1ドット＝1px。テクスチャは最近傍（ぼかさない）。
- 【現状】戦闘背景: 640×360の絵を2倍（1ドット＝2px）。
- 【現状】タイトルの部屋: 640×360（宇宙飛行士・武者）、320×180（紳士）を最近傍で拡大。
- 【現状】VFX: 4px格子のもの（ゴーレムの地割れ等）、滑らかな図形のもの（宇宙飛行士の爆発・騎士の斬撃等）、シェーダーのもの（武者の墨・宇宙飛行士の重力など）が混在している。今の画面は全体に整っており、大きな違和感にはなっていない（QUALITY_AUDIT QA-35）。
- 規約（COMBAT_PRESENTATION §6.1）: 目的は「すべての画素の大きさを数学的にそろえること」ではなく**「ドット絵として一貫して見えること」**。1px／2px格子に合わせるのが基本。滑らかなVFXや高解像度のシェーダーも、縁の処理・明暗・色・タイミング・形・構図がドット絵と調和し、ユーザーが動画で承認したものは使ってよい。
- 【未決定 / USER DECISION REQUIRED】全画面時の拡大方式（fractional／integer）。比較の手順は UI_UX §10.1。

## 3. キャラクター
- 【現状】輪郭: シルエットの外側を暗い色（黒に近い暗色）の線で囲む。
- 【現状】陰影: 素材ごとに2〜3段の明暗で塗り分ける（セル調）。目は小さな黒い点。頭が大きめのデフォルメ体型。
- 【現状】彩度: 服や武器は中〜高彩度（赤いマント、緑の着物、青緑の服など）。確認した夜の背景（中庭）より彩度・明暗差が大きく、背景から浮いて見える。
- 【現状】大きさ（表示の高さ）: 味方82〜112px、ボス150〜180px（覚醒後の武者は約194px）。宇宙飛行士は116pxで味方とほぼ同じ（QA-27、存在感の出し方は【未決定】）。
- 【現状】配置: 味方4人は画面の左半分に2列で並び、ボスは右に立って向かい合う。
- 【判断の問い】同じ画面に並ぶキャラ同士で、輪郭・陰影の段数・彩度がそろっているか（COMBAT_PRESENTATION §6.2）。ボスは大きさか、目立つシルエットで味方と区別できるか。

### 3.1 ボスのテーマ（承認済みの演出から分かること）
- 【固定】朽ちた機械武者: 墨・筆の線・コマ送り。覚醒後は黒墨を**足元だけ**に置き、戦場全体の彩度と明るさを落とす（体のまわりの霞・浮遊する墨粒は不採用）。
- 【固定】竜: 黒い炎、覚醒で暗転して赤い目だけが残り、黒い体と赤い翼へ。
- 【固定】宇宙飛行士: 星雲、重力の波、紫の渦。
- 【固定】異形紳士: 煙、銃、霧のロンドン風の部屋（タイトル）。着弾の暗さは承認済みのv8（見えにくさは QA-28 で【未決定】）。
- 【現状】スライム・狼・騎士・ゴースト・ゴーレム: 承認時のテーマの言葉は記録がない。色・形は今の素材に従う（例: ゴーレムは紫の岩、騎士は暗い鎧に紫）。
- 【未決定 / USER DECISION REQUIRED】各ボスのテーマを言葉で定義した表（下の §9 のテンプレート）。特に古いボス5体。

## 4. 背景・環境
- 【固定】ボス専用の戦闘背景（竜・武者・宇宙飛行士・紳士は承認済み）。専用背景がないボスは、Creatorで選んだ昼／夜の中庭。
- 【現状】確認した夜の中庭: 暗い石造りで彩度を抑え、一番明るいのは松明などの光源。
- 【未決定 / USER DECISION REQUIRED】メニュー背景（ボス作成トップ・モード選択・挑戦ハブ）の画風。今は細密に描き込んだ絵で、ドット絵と画風が違う（QA-25）。
- 【判断の問い】背景が主役（キャラ・命中点）を食っていないか。背景の一番明るい所・一番彩度の高い所が、キャラや命中点と重なっていないか。

---

## 5. Lighting・Depth・Negative Space・Visual Density
- 【現状】Lighting: 夜の場面が多く、光は局所的（松明・炎・画面の発光）。覚醒で照明そのものを変える（竜の暗転、武者の彩度低下）。
- 【現状】Depth: 床の遠近（石畳）と2列の配置で奥行きを出している。カメラは固定（`Camera2D` なし）。
- 【現状】Negative Space: 戦闘HUDは右の列と下の帯。戦場は画面の中央〜左。
- 【現状】Visual Density: 待機中は情報量が少なく、技の時だけ増える。
- 【判断の問い】技の最中に、画面のどこを見ればよいかが一か所に決まっているか。空いている所（negative space）があるから主役が目立つ、という関係が保たれているか。

---

## 6. VFX とキャラ・背景の関係
- 【固定】属性の色（攻撃のVFXだけに使う）: 無 #b7bbc2・炎 #ef4847・氷 #509cf5・雷 #f2cd55・風 #a4f255。支援は強化 #ef4847・回復 #71da87。キャラの本体・岩・土煙は染めない（ゴーレム・狼・騎士の採用時の決まり）。
- 【判断の問い】（COMBAT_PRESENTATION §5、`[R1]`）
  - VFXの見た目の強さ（大きさ・明るさ）が、その技のゲーム上の重要度と合っているか。
  - VFXの情報量がキャラの情報量を上回って、誰が何をしたかが読めなくなっていないか。
  - 一番明るい所が、一番見てほしい一点（命中点）になっているか。
  - そのボス・キャラのテーマ（§3.1）と形・色が一致しているか。

---

## 7. UI と戦闘演出の関係
- 【現状】UIの配色は2系統ある。
  - 基本のテーマ（`rbm_ui_theme.gd`）: 暗い灰青の地（#14171d・#1d2129）、枠 #383e49、文字 #e7e9ed、アクセントの橙 #ba652f。
  - ボス作成の画面（`rbm_creator_ui_kit.gd`）: 暗い青緑の地（#0b0f14）、枠 #2f5b61、明るいシアン #43efff。
- 【未決定 / USER DECISION REQUIRED】2系統の配色を意図して使い分けているかの記録がない。統一するか、使い分けを決まりとして書くか。
- 【現状】戦闘UI（BattleHUD）は戦場の上（z=20）。VFXをUIの上に出すのは意図した全画面演出の瞬間だけ（武者の前例）。
- 【未決定 / USER DECISION REQUIRED】大技の間にHUDを薄くするか（QA-26）。
- 【判断の問い】UIが戦場より目立っていないか（戦闘中は戦場が主役。UI_UX §2）。UIの枠・色が、戦闘のドット絵と同じゲームに見えるか。

## 8. Focus Hierarchy（画面の中の注目の順）
既存の規約（COMBAT_PRESENTATION §5.2・§5.5、UI_UX §2）から読み取れる、戦闘中の注目の順。新しい決定ではない。

1. 今行動しているキャラと、命中の中心
2. 被弾した対象とその反応
3. 他のキャラ
4. 背景
5. HUD（ただし結果の文字は必ず読めること）

- 【判断の問い】1コマ止めた時に、この順で目が動くか（Review I）。順番が崩れているなら、明暗（value）・彩度・大きさ・動きのどれが原因かを特定してから直す。

## 9. 新しいボス・キャラのテーマを決める時のテンプレート

```
名前:
テーマ（言葉で3〜5個）:
シルエットの特徴:

形の言葉（Shape vocabulary。鋭い／丸い／重い塊／細い線／放射／渦／爆発／流線 など）:
動きの性格（重さ・速さ・間）:
音の性格:
環境（専用背景・照明）:
覚醒で何が変わるか:
やってはいけないこと:
承認日・承認した映像:
```
